# Module 02: Lọc Nâng Cao Và Toán Tử Điều Kiện

## 🎯 Mục Tiêu
- Kết hợp nhiều điều kiện với `AND`, `OR`, `NOT` và hiểu thứ tự ưu tiên
- Lọc theo danh sách với `IN` / `NOT IN`
- Lọc theo khoảng giá trị với `BETWEEN ... AND ...`
- Tìm kiếm mẫu chuỗi với `LIKE`, `ILIKE` và ký tự đại diện (`%`, `_`)
- Xử lý giá trị rỗng với `IS NULL` / `IS NOT NULL`
